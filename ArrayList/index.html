Java ArrayList

?

What is an ArrayList?

  • A collection that can change size dynamically
  • Stores objects
  • Can add or remove elements
  • Similar to an array, but resizable

Key Idea

Array = Fixed Size
ArrayList = Resizable

Slide 2 / 15

Creating an ArrayList

Syntax

First, import ArrayList:

import java.util.ArrayList;

Create an ArrayList:

ArrayList<String> fruits = new ArrayList<>();

Breakdown

  • ArrayList → collection type
  • <String> → type of elements
  • fruits → ArrayList name
  • new ArrayList<>() → creates the ArrayList

Example

ArrayList<Integer> numbers = new ArrayList<>();

ArrayList & Data Types

ArrayLists Store Objects. They use wrapper classes for primitive types.

PrimitiveWrapper
intInteger
doubleDouble
booleanBoolean
charCharacter

Example:

ArrayList<Integer> numbers = new ArrayList<>();
Java automatically converts between primitives and wrapper objects using autoboxing.

Adding Elements

.add()

Use .add() to add an element.

ArrayList<String> fruits = new ArrayList<>();

fruits.add("Apple");
fruits.add("Orange");
fruits.add("Banana");

Result:

[Apple, Orange, Banana]

Key Point

The ArrayList automatically grows when elements are added.

Accessing Elements

.get()

Use .get(index) to access an element.

System.out.println(fruits.get(0));
// Output: Apple

Just like Arrays:

Indexes start at 0

Index:    0        1        2
        Apple    Orange   Banana
fruits.get(1);

→ Orange

Changing Elements

.set()

Use .set(index, value) to change an element.

fruits.set(0, "Pineapple");

Before: [Apple, Orange, Banana]

After: [Pineapple, Orange, Banana]

Remember

.get() → Get an element
.set() → Change an element

Removing Elements

.remove()

Use .remove(index) to remove an element.

fruits.remove(1);

Before: [Apple, Orange, Banana]

After: [Apple, Banana]

The ArrayList automatically adjusts its size.

Getting the Size

.size()

Use .size() to find the number of elements.

int numberOfFruits = fruits.size();

Example: [Apple, Orange, Banana]

fruits.size() → 3

⚠️ Don't confuse:

Array     → .length
ArrayList → .size()

Sorting an ArrayList

Collections.sort()

Import:

import java.util.Collections;

Sort the ArrayList:

Collections.sort(fruits);

Before: [Orange, Apple, Banana]

After: [Apple, Banana, Orange]

Remember

Array     → Arrays.sort()
ArrayList → Collections.sort()

Slide 11 / 15

ArrayList + User Input

Example: Storing Food

An ArrayList is useful when the number of elements can change.

ArrayList<String> foods = new ArrayList<>();

Scanner scanner = new Scanner(System.in);
System.out.print("How many foods? ");
int numOfFood = scanner.nextInt();
scanner.nextLine();

for (int i = 1; i <= numOfFood; i++) {
    System.out.print("Enter food   " + i + ": ");
    String food = scanner.nextLine();
    foods.add(food);
}

Example Output:

How many foods? 3

Food   1: Pizza
Food   2: Burger
Food   3: Taco

[Pizza, Burger, Taco]
Key Idea: User input → .add() → ArrayList
