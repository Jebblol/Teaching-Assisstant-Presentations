Java Arrays

?

What is an Array?

  • A collection of multiple values
  • All values must have the same data type
  • Think of it as a variable that can store multiple values

Example

String[] fruits = {"Apple", "Orange", "Banana", "Coconut"};
One variable → multiple related values

Creating an Array

Array Syntax

String[] fruits = {"Apple", "Orange", "Banana"};

Breakdown:

  • String → data type
  • [] → tells Java this is an array
  • fruits → array name
  • { } → contains the elements

Example

int[] scores = {85, 90, 78, 92};
Rule: Every element must have the same data type.

Array Index

Arrays Start at Index 0

Index:     0          1          2          3
         ┌────────┬────────┬────────┬────────┐
Array:   │ Apple  │ Orange │ Banana │ Coconut│
         └────────┴────────┴────────┴────────┘
System.out.println(fruits[0]);
// Output: Apple

Remember:

  • First element = index 0
  • Last index = length - 1

Accessing & Changing Elements

Access an element

System.out.println(fruits[2]);
// Output: Banana

Change an element

fruits[2] = "Mango";

Now: Apple, Orange, Mango, Coconut

⚠️ Invalid Index

fruits[4];

There is no index 4 → ArrayIndexOutOfBoundsException

Array Length

Use .length to find the number of elements.

.length

int numberOfFruits = fruits.length;

For: Apple | Orange | Banana | Coconut

fruits.length → 4

Important!

Length ≠ last index
Length:     4
Indexes:    0   1   2   3
                        ↑
                    Last index

Looping Through an Array

Normal for Loop

for (int i = 0; i < fruits.length; i++) {
    System.out.println(fruits[i]);
}

How it works:

i = 0 → fruits[0]
i = 1 → fruits[1]
i = 2 → fruits[2]
i = 3 → fruits[3]

Why use a loop?

Instead of writing:

System.out.println(fruits[0]);
System.out.println(fruits[1]);
System.out.println(fruits[2]);
System.out.println(fruits[3]);

We can let the loop handle it.

Slide 7 / 11

Enhanced for Loop

Also called a For-Each Loop

for (String fruit : fruits) {
    System.out.println(fruit);
}
For every fruit in fruits, print the fruit.

Normal vs Enhanced for

Normal for loop

for (int i = 0; i < fruits.length; i++)

→ Useful when you need the index


Enhanced for loop

for (String fruit : fruits)

→ Useful when you just need each element

Useful Arrays Methods

First import: import java.util.Arrays;

Sort

Arrays.sort(fruits);

Before: Apple → Orange → Banana → Coconut

After: Apple → Banana → Coconut → Orange

Fill

Arrays.fill(fruits, "Pineapple");

Result: Pineapple → Pineapple → Pineapple → Pineapple
